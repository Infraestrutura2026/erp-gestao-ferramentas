# ERP Complexo Penal de Marília

Sistema de Gestão de Ferramentas e Estoque - Polícia Penal

## Como usar

1. Extraia o arquivo ZIP em uma pasta
2. Abra o arquivo `index.html` no navegador (Chrome, Edge, Firefox)
3. Na primeira tela, crie uma conta clicando em "Primeiro Acesso"
4. Após fazer login, vá em "Configuração" no menu lateral
5. Cole a URL do seu Google Apps Script e clique em "Salvar Configuração"
6. Pronto! O sistema está funcionando

## Cores das Categorias

- Ferramenta Elétrica: Azul (#1565c0)
- Ferramenta Manual: Verde (#2e7d32)
- Material de Consumo: Laranja (#e65100)
- Equipamento de Segurança: Vermelho (#c62828)
- Limpeza: Roxo (#6a1b9a)
- Outros: Cinza (#455a64)

## Suporte

Em caso de dúvidas, o sistema possui mensagens de erro claras na tela.

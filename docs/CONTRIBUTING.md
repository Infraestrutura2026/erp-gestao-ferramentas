# Guia de Contribuição

Obrigado por contribuir com o ERP de Gestão de Ferramentas!

## Como Contribuir

1. **Fork** o repositório
2. Crie uma **branch** para sua feature:
   ```bash
   git checkout -b feat/nome-da-feature
   ```
3. Faça seus commits seguindo as convenções:
   - `feat:` nova funcionalidade
   - `fix:` correção de bug
   - `docs:` documentação
   - `refactor:` refatoração
   - `style:` formatação
4. Abra um **Pull Request** descrevendo suas alterações

## Padrões de Código

- Use **2 espaços** para indentação
- Siga a estrutura modular existente em `assets/js/modules/`
- Mantenha funções pequenas e com responsabilidade única
- Adicione JSDoc em funções públicas

## Reportando Issues

- Use labels apropriadas: `bug`, `feature`, `docs`, `help wanted`
- Descreva o passo a passo para reproduzir bugs
- Inclua prints de tela quando possível
